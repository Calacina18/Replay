# Arquivos de gameplay

Coloque aqui os vídeos que serão cadastrados em `../catalogo.js`.

- Use nomes simples, sem espaços, como `valorant-ace.mp4`.
- Capas podem ficar em `capas/` e legendas `.vtt` em `legendas/`.
- O campo `url` no catálogo aponta para o vídeo; `coverUrl` e `captionUrl` são opcionais.
- Cada arquivo no GitHub precisa ter menos de 100 MB. Mantenha o repositório e o site pequenos.

Quando você fizer commit e publicar o repositório no GitHub Pages, os vídeos também ficarão públicos junto com o site. Para manter um vídeo privado, não o coloque neste repositório.
